# نور المعرفة

لعبة تعليمية عربية RTL عن الأنبياء والرسل، السيرة النبوية، الصحابة والخلفاء الراشدين، والغزوات والفتوحات. المشروع ثابت بالكامل ويعمل على GitHub Pages دون خادم أو قاعدة بيانات.

## التشغيل المحلي

شغّل أي خادم ملفات ثابت من جذر المشروع، مثل:

```bash
python3 -m http.server 3000
```

ثم افتح `http://localhost:3000`.

## النشر على GitHub Pages

ارفع محتويات هذا المجلد إلى مستودع GitHub، واجعل GitHub Pages يعمل من فرع `main` ومجلد `/root`. سيكون `index.html` هو نقطة الدخول، وكل الملفات النسبية ستعمل معًا.

## هيكل المشروع

- `index.html`: واجهة اللعبة.
- `css/style.css`: التصميم المتجاوب RTL.
- `js/questions.js`: بنك الأسئلة وبيانات الإجابات.
- `js/app.js`: منطق اللعبة والحفظ المحلي والمصادر والإحصائيات والأوضاع المتعددة.
- `sw.js`: تخزين الملفات الأساسية للعمل دون اتصال بعد أول زيارة.
- `manifest.webmanifest`: تعريف PWA اختياري.
- `manus-routes.json`: مسار الصفحة الرئيسية لمنصة المعاينة.

## الخصوصية والحدود

لا توجد حسابات أو بيانات ترسل إلى خادم. التقدم والنتائج تحفظ محليًا في المتصفح عبر `localStorage`. المصادر العامة ظاهرة داخل اللعبة، ويجب تدقيق أي محتوى ديني قبل استخدامه في نشر رسمي واسع.
